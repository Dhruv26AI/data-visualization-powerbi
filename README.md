# Power BI Sales Dashboard

## 📊 Overview
This project presents an interactive Power BI dashboard analyzing sales, profit, and cost across different regions, segments, and categories.

##  Features
- Sales, Profit, and Cost KPIs
- Sales by Sub-Category analysis
- Segment-wise performance insights
- Region-wise sales distribution
- Interactive filters (Order Date, Ship Mode)

## Tools Used
- Power BI
- Data Visualization
- Data Analysis
